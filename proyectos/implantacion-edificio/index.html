FOTOGRAMETRÍA · BIM

Cálculo de volumen de excavación e implantación de edificio

Oruro · Bolivia

Del terreno existente al modelo BIM

Se realizó el levantamiento fotogramétrico del terreno como base para determinar el volumen de excavación necesario para la ejecución del proyecto.

A partir de la información obtenida del levantamiento se generaron productos digitales del terreno, incluyendo el modelo digital de elevación y curvas de nivel.

Posteriormente, la información del terreno fue utilizada como referencia para apoyar la implantación del modelo BIM del edificio mediante Revit.

Ficha técnica

Ubicación Oruro, Bolivia
Tecnología Drone · Aerofotogrametría · BIM
Software BIM Autodesk Revit
Productos MDE · Curvas de nivel
Aplicación Cálculo de excavación e implantación

Implantación del proyecto

Integración de la información del terreno con el modelo BIM del edificio para visualizar su implantación sobre las condiciones existentes.

Flujo de trabajo

01

Levantamiento

Captura aérea del terreno mediante drone para obtener información espacial de las condiciones existentes.

02

Procesamiento

Procesamiento fotogramétrico para generar el modelo digital de elevación y productos derivados.

03

Análisis

Utilización de la información del terreno como base para determinar las condiciones necesarias para la excavación.

04

Implantación BIM

Integración del terreno con el modelo BIM del edificio para visualizar su implantación.
